# Аналитика квартир Москвы

Аналитика вторичного рынка квартир Москвы: цены, площади, этажность, метро и относительная выгодность объектов.

[Открыть дашборд](https://GavrikovAlex.github.io/live_data/projects/apartments-moscow/dashboard.html) · [Источник данных](https://www.restate.ru)

## Что внутри

- `scraper/collect_ids.py` — сбор ID из разрешённых каталогов `www.restate.ru` c пагинацией и rate limit.
- `scraper/parse_detail.py` — разбор разрешённых detail-страниц, фильтрация и создание обезличенного sample.
- `src/transform.py` — нормализация чисел, дат и вычисление возраста объявления.
- `src/metrics.py` — сводные метрики, score выгодности и агрегаты для графиков.
- `src/build_dashboard.py` — автономный standalone HTML с Plotly и клиентскими фильтрами.
- `data/sample.json` — 50 обезличенных записей реального вторичного рынка Москвы.

Полные `data/ids.json` и `data/listings.json` создаются локально или в workflow и не добавляются в репозиторий.

## Источники

Сбор идёт только по разрешённым страницам `https://www.restate.ru`:

- `/area/moscow/<id>/...` — срезы административных округов Москвы (id 1–11);
- `/metro/moscow/<id>/...` — срезы станций метро;
- `/adr/moscow/<slug>/...` — срезы адресов.

По умолчанию используются 33 каталога: 11 округов × 1-, 2- и 3-комнатные квартиры на вторичном рынке.
Записи из разных каталогов чередуются round-robin, поэтому ограничение `--max-listings`
не смещает выборку в один округ или один тип квартир.

Не обходятся `msk.restate.ru`, а также пути `/*choice/`, `/*dist/` и `/*complex/`.

## Метрики

На дашборде показаны:

- количество объявлений;
- средняя цена;
- медианная цена;
- средний этаж;
- средняя площадь;
- средняя цена за м².

Restate не отдаёт цену за м² на detail-страницах, поэтому она считается в `src/transform.py`
как `цена / общая площадь`. Значение `null` в `data/sample.json` означает «нет данных у сайта»,
а не «не рассчитано».

Score выгодности рассчитывается относительно средней цены за м² в том же метро:

```text
score = (средняя_цена_за_м²_по_метро − цена_за_м²_объекта)
        / средняя_цена_за_м²_по_метро × 100%
```

Чем выше score, тем больше цена объекта ниже средней по метро. Если для метро нет данных, используется средняя цена за м² по всему срезу.

## Графики

1. Распределение цен.
2. Цена и площадь.
3. Топ-10 метро по средней цене.
4. Динамика по месяцам; если дат недостаточно, показывается распределение по комнатам.

## Фильтры

Фильтры работают в браузере без сервера:

- количество комнат;
- диапазон цены;
- диапазон площади;
- диапазон этажа;
- метро.

## Обезличивание данных

В репозитории хранится только обезличенный сэмпл из 50 объектов реального вторичного рынка.
В нём нет точных адресов, ссылок на объявления, ID, контактов продавцов и фотографий.
Сохраняются только агрегированные поля: округ, район, метро, цена, площади, этаж, число комнат и дата публикации.
Полные локальные выгрузки `data/ids.json` и `data/listings.json` исключены из Git.

## Как запустить локально

Из корня проекта:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python scraper/collect_ids.py                 # ~35 каталогов, пагинация до 2 страниц
python scraper/parse_detail.py --max-listings 130
python src/build_dashboard.py
```

Тесты парсеров не требуют сети:

```bash
pip install -r requirements-dev.txt
python -m pytest tests -q
```

После сборки откройте `dashboard.html` в браузере. Сервер и база данных не нужны.

Ограничить нагрузку можно флагами `--delay` (секунды между запросами, по умолчанию 2),
`--max-pages` (страниц на каталог) и `--max-listings` (сколько detail-страниц разобрать).

## Как обновляется

GitHub Actions запускает workflow раз в день в 03:00 UTC:

1. Собирает ID из 33 разрешённых каталогов Restate.
2. Разбирает до 130 detail-страниц с интервалом не менее 2 секунд.
3. Обновляет только обезличенный `sample.json` и `dashboard.html`.
4. Публикует standalone-дашборд через GitHub Pages.

Сырые `ids.json` и `listings.json` остаются на раннере и в Git не попадают.
Если фильтры отсеивают почти все объявления, workflow сохраняет прежний сэмпл,
чтобы дашборд не оставался пустым.

Файл workflow: [`.github/workflows/apartments-update.yml`](../../.github/workflows/apartments-update.yml).

## Ограничения

- Используются только открытые страницы `www.restate.ru`, разрешённые robots.txt.
- `msk.restate.ru`, `/choice/`, `/dist/` и `/complex/` не обходятся.
- Между сетевыми запросами выдерживается интервал не менее 2 секунд.
- Каталоги Restate меняются и не гарантируют полный снимок рынка.
- Score — относительный ориентир, а не юридическая или инвестиционная оценка.
